# BitStream Audio — public asset host

Public file hosting for BitStream Audio, used where a service requires a fetchable HTTPS URL
rather than a file upload.

**Everything here is already published elsewhere.** Nothing unreleased is hosted in this
repository, and nothing here is confidential.
